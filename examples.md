# Example tasks for the agent

**Coding**
- Write a Python script that renames all .txt files in the workspace to lowercase, then test it.
- Create a small Flask app with one /health route and run its tests.

**Scraping**
- Scrape https://example.com and save the page text and links to example.md.
- Collect the titles from a blog's front page and save them as titles.csv.

**Web interaction** (needs approval for clicks and typing)
- Open a page in the browser, click the "More" link, and screenshot the result.

**Combined**
- Scrape a list of items from a page, write a script that sorts them, and save the result.

Tip: be specific about the output file name, and always say where to stop.
